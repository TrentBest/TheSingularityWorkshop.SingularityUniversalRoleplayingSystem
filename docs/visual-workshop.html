01 · Meaning

Author the model

Start with the SURPS concept and the relationships it must communicate. The behavior diagram is a recursive semantic GUI tree; the encounter map is a typed Visualize vector scene. Neither is hand-drawn as final SVG markup.

02 · Manifestation

Inspect the artifact

GUI.SVG renders the semantic tree; Visualize serializes the authored map primitives. Open both SVGs, inspect their labels and stable entity metadata, and compare the generated outputs.

03 · Improve

Change and regenerate

Improve the semantic tree or the Visualize scene model in its C# proof source, then let the Pages workflow regenerate both artifacts. The generated SVG is the review surface; the typed source model is where changes are authored.

Honest boundary: this first proof is a deterministic, static SVG generated by the actual GUI.Core and GUI.SVG C# projects during publication. The tactical map is generated by Visualize's typed C# SVG document model and copied into the publication artifact; it is a deterministic CPU-side illustration, not an interactive editor, authoritative encounter state, or GPU rendering. The two generators run during the Pages build. Interactive in-page authoring and a live editable SURPS-to-Visualize bridge remain later stages.

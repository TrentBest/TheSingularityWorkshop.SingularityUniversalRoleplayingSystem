## Quick resolution reference

Roll **2d6 + one relevant approach** against the referee's target.

| Result | Resolution |
|---|---|
| Target + 3 or more | Strong success |
| Target to target + 2 | Success |
| Target - 1 or -2 | Mixed result |
| Target - 3 or less | Miss |

Do not roll when there is no meaningful uncertainty or consequence. State intent, method, and risk before rolling. Record what changes.

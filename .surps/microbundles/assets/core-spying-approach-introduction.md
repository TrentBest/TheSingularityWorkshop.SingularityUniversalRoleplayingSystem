# The six approaches

CORE Spying describes an uncertain action through the approach that best explains how the character acts: Observe, Deceive, Infiltrate, Analyze, Influence, or Operate.

An approach rating describes capability, not a guaranteed outcome. The final chance of success also depends on the task, opposition, environment, tools, preparation, and consequences. The same canonical explanation can be included in a player book, a game-master reference, or a Workshop inspection without creating competing copies.

# The Missing Ledger

**Scenario Experience:** `surps.demo.missing-ledger@0.1.0`  
**Status:** first public, player-facing Pages prototype.

A compact, setting-light spy mission built on the canonical CORE Spying book. It selects the existing book by stable ID and compatible version range; it does not copy or redefine its rules or MicroBundle records.

## Play

[Open The Missing Ledger on GitHub Pages](../../docs/experiences/missing-ledger/).

This page is a guided tabletop play aid. Players can declare intent and approach, roll or enter 2d6, record information states, and track scene pressure. A human referee still sets difficulty, describes risks, adjudicates outcomes, and maintains the private fact ledger.

The published player page deliberately contains no referee-only facts. Keep the referee ledger off the public Pages site and share it only through an appropriate private channel at the table.
